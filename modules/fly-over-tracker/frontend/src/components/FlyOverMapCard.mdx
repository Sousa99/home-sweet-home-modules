# FlyOverMapCard

`FlyOverMapCard` is a self-sufficient, embeddable map card for a dashboard: a read-only
map of a configured location and radius with every aircraft inside the radius marked at
its reported position. It renders **no list**, so a host can place the map and the
aircraft list (see `FlyOverListCard`) independently in different regions of a layout.

It fills its container (the map expands to the available space). The card fetches and
auto-refreshes its own data, so a host application only supplies configuration through
props — no data wiring or TanStack Query setup is required.

## Usage

```tsx
import { FlyOverMapCard } from '@sousa99/fly-over-tracker-components';

<FlyOverMapCard location={{ lat: 48.8566, lng: 2.3522, radiusKm: 50 }} autoRefresh={10} />;
```

## Behavior notes

- **Self-sufficient data** — fetches `GET {baseUrl}/api/fly-overs` and re-fetches
  automatically every `autoRefresh` seconds (`'off'` disables automatic refresh).
- **Status bar** — the standardized status bar shows `Last updated {HH:MM:SS}` (or
  `Not updated yet` before the first load), an `Updating…` indicator while a refresh is
  in flight, a `Refresh` button, and a failure notice when the feed is down.
- **Layout** — `w-full`, `h-full` flex column: the map is `flex-1`. Mount it inside a
  container with a defined height.
- **Basemap** — defaults to OpenStreetMap tiles; override with the optional `tileUrl` prop
  (Leaflet `{z}/{x}/{y}` placeholders).
- **Diagnostics** — set `debug` to log the measured container size, zoom, re-fits, and
  tile load/error totals to the console (`[fly-over-map]`) — useful when the map is hosted
  inside a grid/flex layout.
- **Requirements** — the host must provide the peer dependencies `react`, `react-dom`,
  `leaflet`, and `react-leaflet`.
