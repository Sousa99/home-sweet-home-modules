# Clock widgets

The clock is published as two widgets with identical props — `ClockCard` (with card chrome) and
`ClockPlain` (without). Both self-contain the live time from the device clock, expand to fill the
available width and height with the readout scaling to fit, and can be constrained by an optional
aspect ratio.

## Props

`ClockPlain` accepts the exact same props as `ClockCard`.
