# TaskDeckWrapper

The **self-fetching** wrapper around `TaskDeck`: it owns retrieval through an injectable
`dataSource` (default: the API client), re-fetches on `refreshRateMs`, and renders loading,
error, and empty states around the deck. This is the component exported for installation in
other products — the "full component with retrieval".

## Default

Fetches once (via a mocked `dataSource` in this story) and renders the swipeable deck.

<Canvas of={TaskDeckWrapperStories.Default} />

## Status bar

Above the deck the wrapper renders the **standardized status bar** shared by every Home
Sweet Home data widget (the internal `@sousa99/homesweethome-components`
`WidgetStatusBar`):

- **`Last updated {YYYY-MM-DD HH:MM:SS <zone>}`** — the device-local full timestamp (date, 24-hour
  time, and timezone) of the last successful load; shows **`Not updated yet`** before the first load
  completes. Every successful load (polling or manual) advances it.
- **`Updating…`** — a transient indicator (polite live region) shown only while a load
  is in flight.
- **`Refresh`** — a manual refresh button that reloads the deck immediately (disabled
  while updating); the `refreshRateMs` polling continues unchanged.
- A **failure notice** (`role="alert"`) when the latest load failed — the last
  successful time stays visible and `Refresh` retries.

## AutoRotating

The deck advances automatically on `autoRotateMs` (2s in this story).

<Canvas of={TaskDeckWrapperStories.AutoRotating} />

## Empty

When the fetched dataset is empty, the wrapper renders the shared card-styled empty state
(`TaskDeckEmpty`) with `No tasks yet.` — or `No tasks match these filters.` when the active
filters exclude everything. The empty card keeps the deck's compact height so the layout does not
collapse.

<Canvas of={TaskDeckWrapperStories.Empty} />

## Slide-up transition

`transitionVariant` is forwarded to the inner `TaskDeck`. The default `slide` reproduces today's
wide 500px exit pan; `slide-up` exits the card vertically (48px up, no sideways travel) while keeping
duration, rotation, and swipe behavior identical — a good fit for dense dashboards.

<Canvas of={TaskDeckWrapperStories.SlideUp} />

## Sizing

The wrapper accepts a `style` passthrough on its root container. The deck inside defaults to a
compact 16rem stage (CSS custom property `--deck-height`); consumers can grow it by passing e.g.
`style={{ '--deck-height': '24rem' }}` — the value cascades to the empty-card container too.
