# TaskDeck

A swipeable card stack that renders tasks as a deck — the top card fully visible, with the
next `stackSize` cards scaled and fanned behind it (Deck Standard 1 style). Drag the top card
past the swipe threshold to advance the deck; it can also **auto-rotate** on a timer and
**loop** forever.

`TaskDeck` is the **presentational** component — it takes tasks as props and does no fetching.
For a self-fetching version, see `TaskDeckWrapper`.

## Default

A deck of six tasks, ordered by urgency (unset urgency sorts last).

## AutoRotating

The deck advances automatically on `autoRotateMs` (2s in this story). The timer pauses during
a drag and resets after a manual skip.

## NoLoop

With `loop` disabled, the deck stops at the last card instead of wrapping back to the first.

## Empty

When the visible task set is empty — the dataset has no tasks **or** every task is excluded by the
active filters — `TaskDeck` renders a visible card-styled empty state instead of blank space. The
message adapts to the cause: `No tasks yet.` for an empty dataset, `No tasks match these filters.`
when filters exclude everything. The empty card keeps the deck's compact stage height, so the
layout does not collapse.

<Canvas of={TaskDeckStories.Empty} />

## Slide and slide-up transitions

The exiting card's travel is controlled by `transitionVariant`:

- **`slide`** (default) — the exiting card pans the full 500px sideways, exactly today's animation.
- **`slide-up`** — the exiting card rises 48px vertically and fades, with **no sideways travel**, so it
  sits calmly next to other widgets in a dense dashboard. The next card rises from the fanned stack
  behind it. Duration, easing, rotation, stack depth, and swipe-dismiss behavior are unchanged.

<Canvas of={TaskDeckStories.Slide} />
<Canvas of={TaskDeckStories.SlideUp} />

## Compact and overridden size

The deck stage defaults to a compact **16rem** height, applied through the CSS custom property
`--deck-height`. Consumers can grow the stage with the existing `style` surface — any value set on
`--deck-height` in the supplied `style` wins over the default. Long task descriptions stay
truncated via `line-clamp` regardless of the stage height.
