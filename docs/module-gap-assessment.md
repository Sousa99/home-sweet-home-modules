## Bridged in the conformance pass (2026-09-28)

### Base URL (all backend-connected modules)

- **SPA runtime env**: each SPA reads `API_BASE_URL` at runtime via `/config.json` (generated by the
  nginx entrypoint from the `API_BASE_URL` container env; default `''` ⇒ same-origin `/api`). The app
  loads it before rendering (`loadApiBaseUrl()` in `src/api/baseUrl.ts`). — FR-008
- **Component/hook prop**: `baseUrl?: string` on every published data-fetching surface —
  bus-catcher `StopCard`, procrastinator-tracker `TaskDeckWrapper`, fly-over-tracker
  `FlyOverWidget` / `ClosestAircraftCard` / `getFlyOvers`. Precedence: prop > SPA env > same-origin
  `/api`. — FR-009, FR-010
- Unreachable configured backends surface a clear error through the existing SPA/component error
  states (no crash, no hang). — FR-011

### Tooling

- **REST port env unified on `PORT`**: fly-over-tracker now reads `PORT` (default 3000) with
  `HTTP_PORT` retained as a backward-compatible alias that wins when both are set.
- **Native DB defaults → repo-root `data/`**: bus-catcher `DB_PATH` default `../../data/bus-catcher.db`;
  procrastinator-tracker `DATABASE_URL` default `../../data/procrastinator.db` (backend + drizzle
  config). Native runs via `pnpm --filter` (cwd = package dir) and the Docker Compose stack now share
  the same common data directory. — FR-018

### Documentation

- **README / setup / AGENTS**: all four modules now follow the standard outline
  (`docs/module-standard.md` §3). bus-catcher, procrastinator-tracker, and fly-over-tracker were
  rewritten to it (current-time was already conformant). — FR-013

## Applied previously (compose-required, low-risk)

- Each backend-connected module's SPA/Storybook nginx gained an env-templated `/api` reverse proxy
  (`BACKEND_UPSTREAM`); empty ⇒ same-origin, no proxy.
- New `Dockerfile.storybook` per frontend module; `Dockerfile.frontend` for current-time.
- Image-level fixes so backends run on a fresh database: bus-catcher ships its `drizzle/`
  migrations; procrastinator-tracker ships its `drizzle/` migrations and the Compose runs
  `node dist/migrate.js` before startup.
- Module Dockerfiles tolerate a missing `npm_token` build secret (local zero-config builds; CI can
  still pass it).
